# SMART ORKHON — News Frontend Design Prompt

Redesign the SMART ORKHON news section using the second Editorial Magazine reference layout and the exact color palette from my uploaded image.

## COLOR PALETTE — STRICT
Use only these five primary design colors:

- `#003135` — Deep Teal: headings, navigation, dark backgrounds.
- `#024950` — Dark Teal: secondary surfaces, footer, dark cards.
- `#964734` — Terracotta: featured labels, important accents, highlighted buttons.
- `#0FA4AF` — Turquoise: active navigation, links, buttons, hover states.
- `#AFDDE5` — Ice Blue: subtle backgrounds, category chips, soft section highlights.

Use white and neutral light backgrounds where needed for readability.

Do not introduce unrelated bright red, purple, orange, or neon colors.

## DESIGN DIRECTION
Create a premium, minimal, modern editorial news website inspired by The Verge.

Preserve the reference layout:
- Clean horizontal header with SMART ORKHON branding.
- Large featured-news hero with oversized Mongolian headline.
- Beautiful Erdenet City photography.
- Latest-news sidebar with thumbnails.
- Horizontal category navigation.
- Three-column news card grid.
- Spacious typography and balanced whitespace.

## VISUAL RULES
- Use Deep Teal for major headlines.
- Use Turquoise for active states and interactive elements.
- Use Terracotta sparingly for important content.
- Use Ice Blue for soft background sections.
- Avoid excessive gradients and decorative elements.
- Maintain strong contrast and readable Mongolian text.
- Subtle hover transitions and rounded cards.
- Professional, elegant, and lightweight appearance.

## FUNCTIONALITY
Keep search, category filters, featured-news slider, article pages, and responsive navigation fully functional.

## RESPONSIVENESS
- Desktop: Editorial grid with featured hero and news sidebar.
- Tablet: Two-column layout.
- Mobile: Single-column news feed with compact navigation.

## TECH STACK
React + Tailwind CSS + Lucide React.

All interface text must be in Mongolian.

## IMPORTANT
Do not change the overall layout of the second reference design. Only adapt its visual identity to the supplied color palette.

Preserve all existing SMART ORKHON functionality.

The finished website should feel like a modern, premium digital news platform for the citizens of Orkhon Province.
